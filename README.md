# Student Performance Analyzer 📊

A beginner-friendly Python project built using NumPy to analyze student academic performance.

## 📌 About the Project

Student Performance Analyzer is a Python-based project that analyzes marks of 10 students across 5 subjects using NumPy.

It calculates student-wise and subject-wise performance, identifies toppers, calculates percentages, and ranks students based on their total marks.

## 🚀 Features

- Store marks of 10 students in 5 subjects.
- Calculate total marks and average marks.
- Calculate student percentages.
- Find highest and lowest marks.
- Perform subject-wise analysis.
- Identify students scoring above 80.
- Check Pass/Fail status.
- Rank students based on total marks.
- Generate a student performance report.

## 🛠️ Technologies Used

## ⚙️ Installation and Usage

**1. Clone the repository**

```bash

```

**2. Navigate to the project folder**

```bash

```

**3. Install dependencies**

```bash

```

**4. Run the project**

```bash

```
